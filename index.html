Build Notes

V6.9 replaces manual Player Display offer/answer copying with short-code Cloudflare signaling, direct WebRTC pairing, chunked scene sync, and explicit Player Display Ready acknowledgement.

V6.8.1 replaces the generic save spinner with a brass line-art D20 animation styled to match the Scene Board UI.

V6.7 adds shared character position/size across scenes plus Lock All and Unlock All controls for setup.

V6.6.4 replaces the Developer Info native dialog with a custom overlay for more reliable opening across devices.

This build includes all cumulative V6.x features and fixes through V6.6.
